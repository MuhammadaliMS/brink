# Security

Brink runs with Accessibility access and reads the trackpad, so security reports matter.

Please don't open a public issue for a vulnerability. Report it privately instead:
[Security → Report a vulnerability](https://github.com/MuhammadaliMS/brink/security/advisories/new).
Include the Brink version, your macOS version and the steps to reproduce.

You'll get a reply as soon as possible. Fixes ship through Brink's built-in updater, and the
report is credited in the release notes unless you'd rather not be named.

Only the latest release gets security fixes.
