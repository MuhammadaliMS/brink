# Code of conduct

Brink follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and assume good faith. Harassment, personal attacks and discriminatory language
aren't welcome in issues, discussions, pull requests or anywhere else the project lives.

To report a problem privately, message the maintainer
([@MuhammadaliMS](https://github.com/MuhammadaliMS)) on GitHub, or use
[a private report](https://github.com/MuhammadaliMS/brink/security/advisories/new). Reports are
read by the maintainer only and handled confidentially.
